Generación = inversor A + B, ambos con medida. Consumo diario = generación + importación − exportación, solo si hay balance del mismo día y perímetro. Las potencias de red son medias por intervalo obtenidas de contadores acumulados conciliados con el resumen KSTAR. No se usa totalActivePower hasta validar unidades/CT y signo. El refresco de gráficos no llama a APIs. La actualización automática optativa consulta Solarman cada 60 minutos como máximo en este navegador y está apagada de inicio; tampoco consulta al abrir el SCADA. El botón manual utiliza el mismo límite. Una actualización puede consumir varias llamadas internas de la API Solarman, por lo que no se interpreta «1/h» como una única petición al proveedor. KSTAR continúa manual, para días cerrados y sin cron.
